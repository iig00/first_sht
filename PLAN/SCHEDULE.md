# スケジュール

## INDEX: PC・HTMLの両方で1ステージのプレイサイクルを遊べる

- 到達目標: PC実行とHTML出力の両方で、1ステージのプレイを開始からクリアまで行える。
- 対象: I-01、I-02、I-03、I-04。
- 作業順: I-01 → I-02 → I-03 → I-04 → INDEX全体テスト。
- 目標時期: 未設定。

### INDEX全体テスト

- PC上で起動し、タイトル画面を挟まずステージ1が始まることを確認する。
- 自機を操作し、自動射撃とダッシュを使って敵01を倒す。
- ステージ1の敵が0秒・4秒・8秒の予定で出現し、全滅後に「STAGE CLEAR」を2秒表示することを確認する。
- Pキーで一時停止・再開でき、「PAUSED」が表示されることを確認する。
- PCウィンドウまたはHTMLのブラウザータブがフォーカスを失うと自動停止し、フォーカス復帰後もPキーまで停止を保つことを確認する。
- HPをゼロにし、最初の0.25秒で暗転し、残り0.75秒は暗転を保ってから同じステージが初期化されることを確認する。
- ステージクリア後の2秒間とHPゼロ後の再開始待ちの間に一時停止し、タイマーが止まり、再開後に残り時間から続くことを確認する。
- HTML出力でも起動、ステージ1のプレイ、Pキー操作、タブのフォーカス喪失・復帰、HPゼロ後の初期化を確認する。
- ステージ2・3のプレイと最終クリアは、後続INDEXで確認する。

## I-01 ゲーム実行基盤

- 作業内容:
  1. SPEC詳細: PC実行とHTML出力の起動・画面仕様を整理する。起動後はステージ1を始める。
  2. DESIGN詳細: Pyxel実行環境、入力、画面描画をつなぐ責務を定める。
  3. コード作成: ゲームを起動し、画面を表示する基盤を作る。
  4. 簡易テスト: PC上での起動・表示とHTML出力の起動を確認する。
- 到達点: PCとHTML出力の双方でゲーム画面を起動できる。
- 確認方法: 両方の実行環境で起動し、画面が表示されることを確認する。
- 目標時期: 未設定。

## I-02 オブジェクトと操作

- 作業内容:
  1. SPEC詳細: 自機、敵01、弾の動作と未決定事項を整理する。
  2. DESIGN詳細: オブジェクト定義、操作、動作設定の分担を定める。
  3. コード作成: 自機、敵01、弾の生成・更新と行動を実装する。
  4. 簡易テスト: 自機の移動・射撃・ダッシュと、敵01の移動・攻撃を確認する。
- 到達点: 自機と敵01が設定された行動を行い、各弾が移動する。
- 確認方法: PC上で各行動と攻撃パターンを確認する。
- 目標時期: 未設定。

## I-03 戦闘処理

- 作業内容:
  1. SPEC詳細: 当たり判定、ダメージ、HP、回復、無敵時の処理を整理する。
  2. DESIGN詳細: オブジェクト間の判定と結果反映の責務を定める。
  3. コード作成: 弾・接触の判定、ダメージ、撃破、回復を実装する。
  4. 簡易テスト: 敵弾・接触それぞれの1HP、同時命中、撃破回復の優先順、敵撃破時の発射元弾削除、無敵時の弾消去と終了時の接触処理を確認する。
- 到達点: SPECで定めた戦闘結果が各オブジェクトに反映される。
- 確認方法: 各攻撃の命中と撃破後の状態変化を確認する。
- 目標時期: 未設定。

## I-04 ステージ進行

- 作業内容:
  1. SPEC詳細: ステージ1の出現設定、クリア、死亡後の再開始を整理する。
  2. DESIGN詳細: ステージ設定と進行管理の責務を定める。
  3. コード作成: ステージ1の敵出現、クリア判定、同ステージの再開始を実装する。
  4. 簡易テスト: 0・4・8秒の出現、全滅後の2秒間のクリア表示、HPゼロ後の暗転とHP・位置・ストック・敵・自機弾・敵弾・予定の初期化、押下中の方向移動、一時停止・再開と遷移タイマーの停止を確認する。最後の敵撃破とHPゼロが同じ更新で起きた場合、再開始を優先することも確認する。
- 到達点: 1ステージを開始し、クリアまたは再開始まで進行できる。
- 確認方法: ステージ1の敵全滅によるクリア、死亡時の暗転・初期化、同時発生時の再開始優先、通常時と遷移中の一時停止・再開を確認する。
- 目標時期: 未設定。

## INDEX: PC・HTMLで全3ステージを完走できる

- 到達目標: PC実行とHTML出力の両方で、ステージ1から3までをクリアできる。
- 対象: I-05、I-06。
- 作業順: I-05 → I-06 → INDEX全体テスト。
- 目標時期: 未設定。

### INDEX全体テスト

- ステージ2で敵02を倒し、ステージ3で敵01・敵02の両方を倒す。
- ステージ1・2のクリア後にHPが全回復し、ダッシュが5個となって次ステージへ進むことを確認する。
- 全3ステージのクリア後、「ALL CLEAR」が表示され、Enterでステージ1へ戻ることを確認する。
- 「ALL CLEAR」中にPキーやフォーカス変更を行っても表示状態が変わらないことを確認する。
- PC実行とHTML出力の両方で全3ステージを確認する。

## I-05 敵02の追加

  1. SPEC詳細: 敵02の追跡、接触攻撃、耐久力を整理する。
  2. DESIGN詳細: 敵02の定義、操作、行動設定の分担を定める。
  3. コード作成: 敵02の生成と自機追跡、接触攻撃を実装する。
  4. 簡易テスト: 毎秒120ピクセルの追跡、16×16の接触判定、3発での撃破を確認する。

- 確認方法: 3発で撃破でき、接触中に自機へSPECどおりのダメージが発生することを確認する。
- 目標時期: 未設定。

## I-06 ステージ2・3の進行

- 作業内容:

  2. DESIGN詳細: 複数ステージの遷移と終了状態の責務を定める。

- 確認方法: SPECの時刻・敵配置と遷移条件に従うことを確認する。

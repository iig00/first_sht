# ステージ進行

## 対象

- IMPLEMENTATIONのI-04「ステージ進行」に関する設計概要。
- ステージの出現設定、敵の生成、クリア判定、死亡後の再開始を扱う。

## 詳細フロー

- [ステージ進行フロー](stage/progression.md)で、出現予定、クリア、死亡後の再開始、一時停止の状態遷移を示す。

## 構成要素の責務

| 要素 | 責務 |
|---|---|
| `config/stages/` | ステージ内の敵の出現順・位置・タイミングを設定する。 |
| `operations/stage/` | 出現予定と進行状態を管理し、敵の生成・クリア・再開始を調整する。 |
| `operations/enemy/` | 生成された敵の行動を更新する。 |
| `objects/` | 自機、敵、弾を含む現在のステージ状態を保持する。 |
| `app/` | ステージ進行の更新と描画を呼び出し、Pキーとウィンドウ／タブのフォーカス変化を進行管理へ渡す。 |
| `rendering/` | 現在のステージ状態、SPECで定める暗転、「PAUSED」表示を描画する。 |

## 出現とクリア

- `operations/stage/`は`config/stages/`の出現予定を読み、該当時点で敵を生成する。
- 出現予定と敵の生存状態は別々に管理する。出現前の敵が残っている間はクリアにしない。
- ステージに設定された敵がすべて撃破され、出現予定も残っていないとき、クリア状態へ移る。
- クリア時は「STAGE CLEAR」を2秒間表示して次のステージへ進む。ステージ3の後は「ALL CLEAR」を表示し、Enter入力でステージ1へ戻る。
- 次ステージ開始時は自機のHPを全回復し、ダッシュストックを5個使用可能にする。
- 敵の個別行動は`operations/enemy/`と`config/behaviors/`へ委ねる。

## 死亡後の再開始

- 自機のHPがゼロになったことを`operations/stage/`が受け取り、画面暗転後に同じステージの初期状態へ戻す。
- HPがゼロになった時点から再開始までの進行時間1秒間はゲーム進行を停止する。最初の0.25秒で暗転し、残りの0.75秒は暗転状態を保つ。
- 初期化対象は自機のHP・位置、ダッシュのストック、敵、弾、出現予定を含む。
- 再開始時に方向キーが押されていれば、その方向への通常移動をすぐに再開する。

## 一時停止

- `operations/stage/`はPキーによる一時停止・再開と、フォーカス喪失による自動一時停止を管理する。
- フォーカスが戻っても一時停止状態を保ち、Pキー入力を受けて再開する。
- 一時停止中はゲーム内状態の更新とタイマーを止める。再開時は停止した時点の状態と残り時間から続ける。
- `rendering/`は一時停止中の現在の画面に「PAUSED」を重ねて表示する。
- 「ALL CLEAR」表示中は一時停止を適用せず、その表示状態を保つ。

## 追加時の境界

- 既存のオブジェクトと行動設定で構成するステージは、`config/stages/`への設定追加で作成する。
- 共通の進行処理に、特定ステージの出現順や敵の固有行動を埋め込まない。

# ゲーム制作の概要

## 目的

Pythonで2Dシューティングゲームを制作する。

## 決定済みの技術方針

- 使用するゲームエンジンはPyxelとする。
- PC上で実行できるものとする。
- PyxelのHTML出力によるブラウザー実行を対応範囲に含める。

## ゲームの基本方針

- 固定画面型の2Dシューティングとする。自機は上方向を向く。
- 敵を放置すると回避の難しい攻撃が発射されるため、次々に撃破して攻撃を阻止することを遊びの中心とする。
- 危険な攻撃にも回避の余地を残す。無敵ダッシュと敵撃破によるHP全回復で立て直せる。
- 失敗時は同じステージを初期状態から繰り返しプレイする。
- 敵全般の出現方向・動きを、上方からの登場や編隊移動に限定しない。

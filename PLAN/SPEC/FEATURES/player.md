# 自機

## 移動

- 矢印キーとWASDの両方で上下左右に移動できる。
- 斜め移動の速さは縦・横移動と同じとする。
- 反対方向の同時入力は、その軸の移動を打ち消す。
- 慣性はなく、入力すると一定速度で移動し、離すとすぐ停止する。
- 通常移動速度は、画面横幅256ピクセルを約3秒で進む速さとする。
- 画面全体を移動できるが、機体は画面外へ出られない。
- 自機の見た目と被弾判定は、ともに8×8ピクセルとする。
- 外見は水色の上向き機体とし、中央に明るい色のコアを置く。
- 開始位置は画面下部の中央、中心座標(128,176)とする。
- ダッシュ時の移動は[dash.md](dash.md)に従う。

## 自動射撃

- 射撃キーは不要とし、移動方向に関係なく上方向へ自動射撃する。
- 自機の正面から1発ずつ発射する。
- ステージ開始直後に最初の弾を発射し、以後0.2秒間隔で発射する。
- 弾は画面縦幅192ピクセルを約1秒で進む速度で上方向に直進し、画面外に出たら消える。
- 弾の見た目と攻撃判定は、ともに幅2・高さ4ピクセルとする。
- 自機弾は明るい水色で描画する。
- 敵に1発当たると、その敵の被弾数を1増やして弾は消え、貫通しない。
- 撃破に必要な被弾数は敵ごとの仕様で定める。
- ダッシュ中と急停止後の無敵中も、射撃は継続する。

## HP・ダメージ・回復

- 最大HPは3とし、HPがゼロになった場合は[stage.md](stage.md)の再開始に従う。
- 敵弾1発の命中と敵本体への接触は、それぞれ1HPのダメージとする。
- 敵を1体倒すたびに、自機のHPが全回復する。
- HPは画面左上の3つの印で表示する。1HP失うごとに1つを暗くし、全回復時にすべて戻す。
- 被弾後の無敵時間は設けない。ダッシュによる無敵は別途適用する。
- 通常時、敵弾は自機に当たるとダメージを与えて消える。
- ダッシュ中と急停止後の無敵中、敵弾は自機に当たると消滅し、自機はダメージを受けない。
- 通常時に複数の敵弾が同時に当たった場合は、弾数分のダメージを受ける。
- 敵本体との接触でも自機がダメージを受ける。敵は接触によるダメージを受けない。
- 接触した瞬間にダメージを受け、重なっている間は0.2秒ごとに追加ダメージを受ける。
- 一度離れて再接触した場合は、前回のダメージから0.2秒以内でも即座にダメージを受ける。
- 複数の敵との接触ダメージは、敵ごとに独立して発生する。
- ダッシュの無敵終了時に敵本体と重なっている場合、その時点で接触ダメージを受ける。そのダメージから0.2秒ごとに追加ダメージを受ける。
- ダメージを受けると自機が一瞬赤く点滅する。これは演出のみで、無敵時間は発生しない。
- 同じタイミングで敵撃破と被弾が起きた場合、先に敵撃破とHP全回復を処理し、その後に被ダメージを適用する。

# ステージ

## 敵の出現と行動

- 敵の出現順・位置・タイミングを、ステージごとにあらかじめ設定する。
- ゲーム起動時にステージ1を開始し、最初の敵は開始時刻0秒に出現する。
- 後続の敵は、前の敵を倒したかどうかにかかわらず、ステージ開始からの予定時刻に出現する。
- 敵はそれぞれに設定された動きと攻撃を行う。
- 敵全般の出現方向は上端に限定しない。
- 敵が画面外へ移動しても、再登場するなど、必ず倒す機会が残るものとする。
- 画面外へ移動しただけでは撃破扱いにしない。

ステージ1は敵01を3体、ステージ2は敵02を3体、ステージ3は敵01・敵02を各3体配置する。

## クリア

- ステージに設定された敵をすべて撃破するとクリアする。
- 未出現の敵が残っている間は、画面内の敵がゼロでもクリアしない。
- 最後の敵の撃破と同じ更新で自機のHPがゼロになった場合は、ステージクリアせずHPゼロ後の再開始を行う。
- 全敵撃破後は「STAGE CLEAR」を2秒間表示し、自動で次のステージを開始する。
- 全3ステージのクリア後は「ALL CLEAR」を表示し続ける。Enterキーでステージ1から再開する。
- 次のステージは、自機のHPを全回復し、ダッシュストックを5個使用可能な状態で開始する。

## 再開始

- 自機のHPがゼロになった場合、画面を暗転させた後、ゲームオーバー画面を挟まず同じステージを初期状態から再開始する。
- HPがゼロになった時点から再開始までの1秒間はゲーム進行を停止する。最初の0.25秒で画面を暗転させ、残りの0.75秒は暗転を保つ。
- 自機のHP・位置、ダッシュのストック、敵、弾、出現スケジュールを含め、ステージを初期状態へ戻す。
- 再開始時に方向キーが押されていれば、その方向への通常移動をすぐに再開する。
- 繰り返しプレイすることを前提とする。

## 一時停止

- Pキーを押すたびに一時停止と再開を切り替える。一時停止中は「PAUSED」を表示し、ゲーム進行を止める。
- PCアプリのウィンドウ、またはHTML版のブラウザータブがフォーカスを失うと、自動で一時停止する。
- フォーカスが戻っても自動再開せず、Pキーを押すと再開する。
- 一時停止中はタイマーを止める。再開後は停止した時点の残り時間から続ける。ステージクリア後の2秒間と、HPゼロ後の再開始までの1秒間も同様とする。
- 「ALL CLEAR」表示中は一時停止の影響を受けず、Pキーやフォーカス変更で表示状態を切り替えない。

決定済み事項の保存であり、ステージ仕様全体の検討完了とはしない。

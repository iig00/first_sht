# 追跡する敵

## 役割

- 敵02は自機へ接近し続け、接触する前に倒すことを促す追跡型の敵とする。
- ステージ2で登場し、ステージ3では敵01と組み合わせる。

## 出現と移動

- 出現位置はステージ設定で指定する。
- 出現後は毎秒120ピクセルで自機の現在位置を追う。
- 自機の位置に合わせて進行方向を即座に変え、接触中も自機を追跡する。
- 自機を通り抜けない。
- 本体の見た目と接触判定は、ともに16×16ピクセルとする。

## 攻撃と撃破

- 弾は発射せず、自機との接触で攻撃する。
- 自機弾が3発当たると撃破される。
- 自機との接触による敵本体へのダメージはない。
- 自機への接触ダメージは[player.md](player.md)に従う。

# 無敵ダッシュ

## 発動と移動

- Shiftキーで発動し、ストックを1個消費する。
- 通常時は移動入力がある場合だけ発動でき、その入力方向へ進む。
- 通常時に移動入力がない場合は発動できない。
- 発動時の方向に固定し、途中でキーを離しても0.2秒間進む。
- 速度は通常移動の3倍とし、斜め方向でも速さは同じとする。
- ダッシュ中はすべてのダメージを無効にする。

## ダッシュ中の追加発動

- ダッシュ中に再度Shiftキーで追加発動できる。追加発動もストックを1個消費する。
- 方向入力がある場合は、その方向へ変更し、変更時点から新たに0.2秒間ダッシュする。
- 方向入力がない場合は急停止する。
  - 移動は即座に止まり、急停止した時点から0.2秒間、すべてのダメージを無効にする。
  - この無敵中も通常移動は可能とする。
- ストックがゼロの場合は、方向変更も急停止も発動できない。
- ダッシュ中・急停止後の無敵中も、自動射撃は継続する。

## ストックとチャージ

- 最大ストックは5個とする。
- ステージ開始・再開始時は5個すべて使用可能とする。
- 消費したストックは、3秒で1個ずつ順番に回復する。並行チャージはしない。
- チャージ中に追加使用しても、進行中のチャージ時間はリセットしない。

## 未決定事項

- 画面端に到達した場合のダッシュ継続時間・移動の扱い。
- 急停止後の無敵中に、移動入力なしで再度Shiftを押した場合の扱い。
- ストックとチャージ進行の表示方法。

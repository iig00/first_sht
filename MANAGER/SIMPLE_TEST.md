# 簡易テスト

- 本文書で定める作業による変更は、AGENTS.mdの「承認依頼と許可」の適用対象外とする。

## 目的と対象

- 対象ID内に収まる関数などの動作を確認する。
- テストの作成・実行・結果確認を一つの工程として扱う。

## 実施時期と作業範囲

- 対象IDの実装リストに従い、コード作成後、ID作業終了前に行う。
- 一回の作業範囲は、実装リストに記載された簡易テストの項目とする。

## 開始時

- 対象コード、仕様に基づく期待結果、検証範囲、実行環境、許可を確認する。
- 既存のテストを確認し、必要な検証の不足と重複を把握する。

## 作業内容

- 対象ID内の関数などについて、仕様上必要な結果を検証する。
- テストコードや補助データを必要に応じて作成し、実行結果を期待結果と照合する。
- 全体テストに相当する検証を独自に追加しない。

## 終了・中断時

- 成功・失敗・未確認を区別して報告し、実装リストの状態を更新する。
- 完了後は実装リスト上の次の作業へ受け渡す。
- 問題がある場合は、事実・影響・必要な対応を報告する。仕様や作業範囲を独自に変更しない。
- 作業の許可と再開は、共通の承認規則に従う。
